# Team Onboarding Chat

## A. 라이브 입력

자동 탐색 결과를 먼저 보여주고, 다음 운영 맥락을 한 번만 입력합니다. 구조 탐색을 다시 요청하거나 새 대화로 이동하지 않습니다.

```text
자동 탐색에서 확인한 서비스 정보에 다음 운영 맥락을 팀 지식으로 추가해 주세요.

- Payments demo 팀은 payments namespace의 payment-api와 payment-provider를 담당합니다. 실제 고객 거래가 없는 실습 환경입니다.
- 정상 기준은 카드·계좌 각각 새 요청 20건에서 실패 0건, p95 1,000ms 이하입니다. Pod Ready나 /health 성공만으로 정상이라고 판단하지 마세요.
- provider 호출 제한은 3초입니다. 한 요청의 타임아웃이 동시 요청이나 이후 요청으로 전파되면 안 됩니다.

위 내용은 팀이 제공한 운영 기준으로 구분해 저장하고, 반영한 지식 파일과 추가 확인이 필요한 내용만 짧게 알려 주세요. 리소스 재탐색·변경이나 테스트 요청 실행은 하지 마세요.
```

## B. 진행과 확인

자동 탐색은 리소스·배포·호출 관계를 파악하는 데 활용하고, 팀이 정하는 담당 범위와 정상 기준은 대화로 보충합니다. 자동 탐색 화면은 실제로 확인된 결과만 설명합니다.

입력 후에는 Knowledge sources·Skill 구성으로 이동합니다. 저장 응답은 돌아와서 확인하되, 라이브에서 별도 확인 프롬프트를 연속 실행하지 않습니다. 새 대화에서 지식을 다시 조회하는 검증은 사전 리허설로 분리합니다. 한 번 입력한다고 처리 시간이 고정되거나 즉시 저장되는 것은 아닙니다.
