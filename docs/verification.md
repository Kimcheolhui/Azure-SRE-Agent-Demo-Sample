# SRE Agent Demo 검증 기록

이 문서는 이전 리허설과 코드 검증의 기록입니다. 사용자 직접 프로비저닝·구성 환경의 준비 상태를 대신하지 않습니다. 현재 구성 방식과 입력 내용은 [진행 가이드](demo-guide.md)를 기준으로 합니다.

## A. 확인한 결과

- 리뷰 보완 후 로컬 테스트 38개 통과.
- 실제 AKS·ACR·SRE Agent를 사용한 이전 리허설에서 장애 재현·조사·복구 확인.
- 자동 인시던트 조사, 지식 저장·검색, 예약 작업의 실제 결과 확인.
- 네이티브 Live Report의 저장 버전과 실제 쿼리 3개 재조회 검증.
- GitHub 소스 게시와 로컬·원격 커밋 일치 확인.
- SVG 글자 초과 4곳을 수정하고 글자 23개·박스 8개·연결선 8개 검증.

이전 복구 실측은 A만 타임아웃, B·C 성공, 카드·계좌 각 20건 실패 0건과 p95 17ms·6ms였습니다. 이후 노드가 할당 해제된 상태와 Pod 준비 실패를 관측했으므로 이 과거 결과로 현재 준비 완료를 주장하지 않습니다.

## B. 코드 보호

- 환경별 이름·ARM ID·소유 태그·실제 엔드포인트 확인.
- 다른 구독·배포 이미지의 릴리스 증거 거부.
- 보고서 승인 설명만으로 자동 승인하지 않음.
- 예약 작업의 신호 중단 정리와 불확실한 resume 기록 유지.
- 환경 파일·키·kubeconfig의 빌드·Git 제외.
- 현재 실행의 새 경고·최종 답변·예약 결과·복구 측정만 인정.
- 저장 보고서의 실제 호출·쿼리 검증과 모호한 변수 범위 거부.

## D. 남은 확인

- azd에 포함할 앱 배포·Agent 생성·권한 범위 확정.
- 직접 배포한 SHA·digest·Code Access 파일 대조.
- 사용자가 로그인한 포털의 구성 화면과 최종 결과 확인.
- 현재 노드·Pod·관측·경고의 실제 준비 상태 확인.
- 기본 이미지의 High 보안 경고 11건에 대한 운영 사용 전 검토.

기존 리허설 자원은 유지되어 과금될 수 있습니다. 사용자의 직접 실행 요청 없이 Azure 배포·SRE Agent 구성을 더 수행하지 않습니다.
